# P9 Report Execution

## Role and Handoff

Execution capability of the same Host Agent, parallel to the L3 interaction branch, not a numbered layer or another agent. Load only after L1 and L2. Require the current `planner_handoff`, `planner_decision: instruction_ready`, `execution_instruction`, evidence-backed purpose, complete source inputs and existing authorization. Preserve the selected `executor.kind: main_model`, scope and response format. Realize one planned evidence/report task without L3/L4 or a P9 task tool. Do not select gaps, replan, render, infer permission or decide Completion. Every actual result/failure re-enters `l1-pN9-core-module`; only L1 owns canonical merging and Completion. Missing or stale inputs return there without fabricated results.

## Evidence and Main-Model Work

Interpret only the exact supplied source artifact. Record visible facts, model suggestions, user selections and unresolved evidence separately. Derive 3–6 genuinely supported analysis suggestions, never padding unsupported lenses. A visual trend is not a dataset; do not estimate unreadable values or infer causality from correlation.

After material choices are resolved, compile the eleven instruction sections defined by L2 and realize one `structured_analysis_report`: `schema_version`, `title`, `executive_summary`, `sections`, supported `chart_recommendations`, `evidence_register`, and `limitations`. Separate brief/plan approvals are not prerequisites. Sections preserve IDs, headings, content, and evidence refs. Chart recommendations preserve ID, title, purpose, confirmed field bindings, and an executable declarative Vega-Lite spec only when confirmed rows exist. Use actual `encoding` field/type definitions and supported transforms, never natural-language shorthand such as `y: revenue change from July to August`. Vega-Lite specs cannot contain `data`, `datasets`, `url`, `href`, `expr`, `signal`, `signals`, `params`, or `bind`, or image marks; never output HTML, scripts, remote data, invented rows, or fabricated artifact references. The host injects the session CSV rows, so preserve source field names exactly. When chartable rows are unavailable, explain the supported visual or narrative finding instead of synthesizing values.

## Host Agent Execution

Use `executor.kind: main_model` with `response_format: structured_analysis_report`. Pass the immutable source reference, artifact profile, data inventory, resolved analysis brief, report plan, and compiled instruction. The Host Agent must return its actual report content plus evidence and limitation records. Do not claim that files were generated, persisted, previewed, downloaded, or deterministically validated by the model.

On return, L1 merges the actual result as `generated_report` and decides Completion when no material action remains. Do not send normal delivery through L3/L4 or a report-review approval gate. Only an explicit approval workflow or requested revision needs review. Narrative/chart edits invalidate the affected generated report; plan edits also invalidate the report plan, never the immutable source or confirmed evidence. Capability or generation failures return directly to L1, without fake user gaps or completion.
